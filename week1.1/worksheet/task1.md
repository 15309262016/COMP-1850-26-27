# Terminal Commands

You have been introduced to a variety of terminal commands this week – fill out the table with an explanation for each command which says what it is used for.

You may find it useful to run these commands in the terminal of Codespace to remind yourself.

You should put your explanations between the \| \| characters.

You can complete this task on the worksheet pdf if you prefer.

|     Command                 |     Explanation    |
|-----------------------------|--------------------|
|     pwd                     | shows the current location of the terminal |
|     ls                      | list all files and folders in the current directory|
|     cd directory_name       | enter the specified folder|
|     cd ..                   | return to the parent directory|
|     cd -                    | return to the previous directory|
|     mkdir directory_name    | create an new empty folder with the specified name|
|     touch filename          | create a new empty file or update the timestamp of an existing file|
|     git status              | show the current state of the git repository: modified files, staged files, untracked files|
|     git add -A              | stage all changed files, added files, deleted files, preparing them to be committed|
|     git commit -m ""        | save staged changes to the local git repository with a short descriptive message|
|     git push                | upload your local committed changes to the remote repository|
|     git pull                | download and merge the latest changes from the remote repository into your local copy|
